◆ FH_CAN05_ReceiveBuf

volatile uint8_t FH_CAN05_ReceiveBuf[]
extern

FH user shall use FH_CAN05_ReceiveBuf in the receive ISR (Interrupt Service Routine) of the CAN 05 in a separate c file
For this to happen, FH user shall just include FH_CAN05_GlobalVariables.h there
In other word, FH_CAN05_ReceiveBuf array shall receive every byte of the received data there
It is configurable in FH_CAN05_Configs.h
