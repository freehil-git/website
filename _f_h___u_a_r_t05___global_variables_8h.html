◆ FH_UART05_ReceiveBuf

volatile uint8_t FH_UART05_ReceiveBuf[]
extern

FH user shall use FH_UART05_ReceiveBuf in the receive ISR (Interrupt Service Routine) of the UART 05 in a separate c file
For this to happen, FH user shall just include FH_UART05_GlobalVariables.h there
In other word, FH_UART05_ReceiveBuf array shall receive every byte of the received data there
It is configurable in FH_UART05_Configs.h
