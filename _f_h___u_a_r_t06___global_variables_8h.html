◆ FH_UART06_ReceiveBuf

volatile uint8_t FH_UART06_ReceiveBuf[]
extern

FH user shall use FH_UART06_ReceiveBuf in the receive ISR (Interrupt Service Routine) of the UART 06 in a separate c file
For this to happen, FH user shall just include FH_UART06_GlobalVariables.h there
In other word, FH_UART06_ReceiveBuf array shall receive every byte of the received data there
It is configurable in FH_UART06_Configs.h
