◆ FH_DO_Init_DO47()

FH_ErrorInfo FH_DO_Init_DO47 ( )

This function initializes the Digital Output 47
The Digital Output 47 could be any interested digital output of the micro-controller on which FH source code is ported
FH user should call the initialization function of the interested digital output here.

Parameters
None
Returns
FH_ErrorInfo is returned
Note
To have a clean code, just include the related header file
Then just call the function here
  ==============================================================================
                        ##### RobotFramework Example #####
  ==============================================================================
  @{MessageData} =    Create List    ${DO47}
  &{Message}     =    Create Dictionary    DeviceAddress=${DeviceAddress_01}    Function=${Function_DO}    Command=${DO_Commands_Init}    Data=@{MessageData}
  ${Result}    SendMessage    &{Message}

  Comments:

  DO47 => It indicates the Digital Output 47
  DeviceAddress_01 => It shall be equal to the address of the device: FH_RFCommunication_DeviceAddress
  Function_DO => It is the function in the message frame
  DO_Commands_Init => It is the command of the function in the message frame
Warning
To be able to set or reset the Digital Output 47 of the micro-controller on which FH source code is ported, this function shall be invoked once by RobotFramework firstly
In other words, before invoking FH_DO_SetStatus_DO47 function from RobotFramework, this function shall be invoked in order to initialize the digital output

◆ FH_DO_SetStatus_DO47()

FH_ErrorInfo FH_DO_SetStatus_DO47 ( uint8_t Status)

This function sets or resets the Digital Output 47
The Digital Output 47 could be any interested digital output of the micro-controller on which FH source code is ported
FH user should call the set and reset functions of the interested digital output here.

Parameters
StatusIf Status is 1, the set function of the Digital Output 47 shall be called
If Status is 0, the reset function of the Digital Output 47 shall be called
Returns
FH_ErrorInfo is returned
Note
To have a clean code, just include the related header file
Then just call the function here
  ==============================================================================
                        ##### RobotFramework Example #####
  ==============================================================================
  @{MessageData} =    Create List    ${DO47}    ${DO_Set}
  &{Message}     =    Create Dictionary    DeviceAddress=${DeviceAddress_01}    Function=${Function_DO}    Command=${DO_Commands_SetStatus}    Data=@{MessageData}
  ${Result}    SendMessage    &{Message}

  Comments:

  DO47 => It indicates the Digital Output 47
  DO_Set => It indicates the Digital Output 47 shall be Set (DO_Reset indicates the Digital Output 47 shall be Reset)
  DeviceAddress_01 => It shall be equal to the address of the device: FH_RFCommunication_DeviceAddress
  Function_DO => It is the function in the message frame
  DO_Commands_SetStatus => It is the command of the function in the message frame
Warning
To be able to set or reset the Digital Output 47 of the micro-controller on which FH source code is ported, the FH_DO_Init_DO47 function shall be invoked once by RobotFramework firstly
In other words, before invoking FH_DO_SetStatus_DO47 function from RobotFramework, FH_DO_Init_DO47 function shall be invoked in order to initialize the digital output
